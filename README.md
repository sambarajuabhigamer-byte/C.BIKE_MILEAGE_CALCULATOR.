# 🏍️ BIKE MILEAGE CALCULATOR - C Program

A simple C program to calculate your monthly and yearly bike fuel expenses.

### 📝 Problem It Solves
Every bike user wants to know how much they spend on petrol per month/year. This calculator gives instant results.

### ⚙️ How It Works
User enters:
- Daily travelling distance (in km)
- Petrol price per litre
- Bike mileage (per litre)

Formula:
Monthly Cost = (daily_km * petrol_price * 30) / mileage
Yearly Cost = Monthly Cost * 12

### 💻 Sample Output

        BIKE MILEAGE CALCULATOR

Enter how many km do you travelling daily (in km): 40
Enter how much fuel cost per litre (in your city): 110
Enter your bike mileage (per litre): 50

Per month fuel cost is 2640.00
Per year fuel cost is 31680.00
